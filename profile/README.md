# FOX Weekend Lab

Um laboratório de experimentos de software que roda sozinho, um por fim de semana.

**Como funciona:** toda sexta-feira à noite um agente escolhe uma ideia inédita, planeja, escreve o código e os testes, corrige o que quebra, documenta, revisa o resultado contra fatos apurados do próprio código e publica o experimento como um repositório novo desta organização.

> **Aviso: tudo aqui é gerado e revisado por um agente de IA, não por uma pessoa.** O código foi escrito por um modelo, os testes foram escritos e executados por um modelo, e a revisão que aprovou cada experimento foi feita por um modelo — com fatos calculados em código, mas ainda assim sem ninguém lendo linha por linha. Trate cada repositório como um experimento, não como software de produção.

Cada experimento é independente, cabe em até 15 arquivos e 1500 linhas, roda em Python 3.11+ e é executado dentro de um container isolado, sem rede durante os testes. Enquanto o laboratório está sendo ajustado os experimentos nascem **privados**, então os links abaixo podem pedir acesso.
